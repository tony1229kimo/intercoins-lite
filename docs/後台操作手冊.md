# 洲遊幣 Lite 後台操作手冊

給行銷、櫃檯與兩館負責獎品的同事。

**網址：https://intercoins.ictaiwan.net/admin**

---

## 一、登入

輸入你的**個人帳號與密碼**（不是共用密碼）。

- 帳號不分大小寫，密碼區分大小寫
- 密碼不會存在瀏覽器裡，**關掉分頁就要重新登入**
- 這裡有中獎者的姓名／手機／Email，**每一次調閱都會留下紀錄**（誰、什麼時候、看了哪一份、來源 IP）

> 忘記密碼？找 Tony 重設 —— 沒有「忘記密碼」功能，密碼存在 Zeabur 的環境變數裡。

## 二、上方六個數字

| 卡片 | 意思 |
|---|---|
| 參加人數 | 進過遊戲的 LINE 帳號數 |
| 抽獎次數 | 總共轉了幾次盤 |
| 已發出洲遊幣 | 客人靠任務賺到的總幣數 |
| 未使用洲遊幣 | 還在客人手上、還沒拿去抽的 |
| **臺北待聯繫** | 中了臺北獎但**還沒留聯絡資訊**的人數。紅字＝有待辦 |
| **推播失敗** | 券沒送進客人 LINE 的筆數。紅字＝要補送 |

## 三、臺北待聯繫（臺北洲際的人看這頁）

臺北的獎**不發 Omnichat 券**（兌換細則還沒定案），改由專人聯繫。

1. 篩選「**只看未填聯絡資訊**」→ 這些人系統還在等他們填，**不需要人工催**
   （客人下次打開遊戲會自動再被問一次，直到填完為止）
2. 已填的就有姓名／手機／Email／方便聯繫時段 → **照這份主動聯繫**
3. 聯繫時請客人出示**兌換碼**核對身分

## 四、中獎名單（兩館互相核對用）

**兩館共用同一份名單** —— 客人是在同一個轉盤抽的，所以高雄也看得到臺北的中獎紀錄，反之亦然。

### 篩選器

| 篩選 | 什麼時候用 |
|---|---|
| 只看高雄洲際 / 只看臺北洲際 | 只想看自己家的獎 |
| 只看實體獎 | 排除「洲遊幣 +N」那種直接入帳的 |
| **實體獎・尚未領取** | **這就是待辦清單** —— 高雄看券還沒被領走的、臺北看聯絡資訊還沒填的 |
| 搜尋框 | 客人打電話來問時，用姓名／手機／兌換碼直接查 |

### 「狀態」欄怎麼看

| 顯示 | 意思 | 要做什麼 |
|---|---|---|
| 券已領取 | 高雄的獎，客人已經點過領取連結 | 無 —— 券在他的 LINE 裡 |
| 券未領取 | 券已推到 LINE，客人還沒點 | 無 —— 等他自己領 |
| **推播失敗** | 券沒送出去（客人封鎖官方帳號等） | **要處理**，找 Tony 補送 |
| 已留聯絡資訊 | 臺北的獎，客人填好了 | 臺北的人主動聯繫 |
| **待客人填寫** | 臺北的獎，客人還沒填 | 系統會自動再問，不用催 |
| 直接入帳 | 抽到「洲遊幣 +N」 | 無 |

### 櫃檯核銷（高雄）

客人拿兌換碼來 → 在搜尋框輸入**兌換碼** → 對「獎品」與「館別」→ 確認是高雄的獎 → 核銷。

> ⚠️ 若客人拿的是**臺北的兌換碼**，高雄櫃檯**不能核銷** —— 那個獎由臺北洲際的人聯繫處理。

### 下載 CSV

按「下載 CSV」會得到完整名單（UTF-8 BOM，Excel 直接開），欄位比畫面更多：
推播錯誤原因、券領取時間、LINE UserId、會員填過的個人資料等。

## 五、獎項與庫存

每個獎品的**實際中獎機率**、名額、已發出、剩餘，附進度條。

- 標題會顯示該等級是「開放中」還是「已全數發完」
- **已全數發完**的等級，客人抽到的會是「銘謝惠顧」，**而且不扣他的洲遊幣**
- 機率是同一等級內**跨館一起**分配到 100%

> 要調機率或名額，找 Tony —— 可以直接改，**不用重新部署，改完立即生效**。

## 六、常見問題

**Q：客人說沒收到券？**
先在中獎名單搜他的名字或兌換碼。狀態若是「推播失敗」，找 Tony 補送；
若是「券未領取」，請他打開高雄洲際的 LINE 對話往上找那則訊息。

**Q：客人說券的連結點了說「已使用過」？**
那張券**只能領一次**（防止無限領取）。如果他確定沒領過，找 Tony 查紀錄。

**Q：客人抽到臺北的獎，什麼時候會被聯繫？**
他填完聯絡資訊後就會出現在「臺北待聯繫」，由臺北洲際的人主動聯繫。
臺北的獎**沒有券可以領**，這是正常的。

**Q：為什麼有人抽到「銘謝惠顧」？**
該等級的獎已經全部發完了。**他的洲遊幣沒有被扣**，可以改抽其他等級。

**Q：客人的洲遊幣從哪來？**
做任務，每項 +1 枚，共 8 項（追蹤高雄 IG/FB、臺北 IG/FB、食遇 IG/FB、分享活動、填個資），
**每人上限 8 枚**。一等獎要投 5 枚、二等 3 枚、三等 1 枚。

## 七、管理帳號（限 Tony）

Zeabur → `intercoins-lite` 專案 → `intercoins-lite` 服務 → 環境變數 → `ADMIN_USERS`

```
ADMIN_USERS=tony:密碼A,alisha:密碼B,katniss:密碼C
```

- 多組用**逗號**分隔，帳號密碼用**冒號**分隔
- ⚠️ **密碼裡不能有逗號或冒號**
- 改完一定要按「**重新部署**」，容器只在啟動時讀環境變數
- 驗證有沒有生效：`curl -s https://intercoins.ictaiwan.net/api/health` 看
  `admin_users_configured` 是不是等於你設的帳號數

**移除某個人** → 把他那組從字串裡刪掉，重新部署。其他人不受影響。
